# Triage labels

| Role            | Label             | Meaning                                                         |
| --------------- | ----------------- | --------------------------------------------------------------- |
| needs-triage    | `needs-triage`    | New; the Explore task has not judged it yet                     |
| needs-info      | `needs-info`      | Waiting on the reporter                                         |
| ready-for-agent | `ready-for-agent` | Clear enough for the Implement task                             |
| ready-for-human | `ready-for-human` | Needs a person: judgment, credentials, or a capped loop ran out |
| wontfix         | `wontfix`         | Out of scope                                                    |

Factory bookkeeping labels (not triage roles): `agent-review`, `rework-1`, `rework-2`, `rework-3`, `spec`.
